# ScanMaster Releases

This repository holds **release artefacts** for [ScanMaster](https://github.com/DeenadayalanMoodley/ScanMaster-releases) — the source-code repository is private, so this public mirror is what the in-app auto-updater consumes.

Every release here corresponds to a tag in the private source repo. The release notes and installers/zips live here only; there is no source code in this repository.

## Latest

See the [Releases page](https://github.com/DeenadayalanMoodley/ScanMaster-releases/releases) for the latest installer (`ScanMasterSetup-x.y.z.exe`) and portable zip (`ScanMaster-x.y.z-portable.zip`).
